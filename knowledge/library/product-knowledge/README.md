# WDP 知识库（团队知识库母版）

面向 WDP（数字孪生PaaS平台）的产品知识管理与任务执行系统，基于在线文档实时同步，支持多场景子任务分发。

> 📌 本目录是**团队知识库母版**，作为工作台知识接入层的参考实现，后续按实际情况调整优化。

## 🔒 授权访问规则（团队规则）

**在线文档需要授权才能查看。统一使用管理员账号授权访问，团队成员不可获取授权信息。**

1. 在线源（企微文档 / 飞书 Wiki / API Skill 库）的访问凭证，**仅管理员配置**（个人环境变量或 K8s Secret）。
2. 凭证（app_id / app_secret / token / 密码）**严禁硬编码进代码、严禁提交进 git、严禁在对话/日志中回显**。
3. 成员使用知识库内容时，**无需也不应接触凭证**——由管理员配置的同步任务拉取后供全员使用。
4. 脚本统一从环境变量读凭证；无凭证时优雅降级（提示管理员配置，不报错中断）。

环境变量约定：
- `FEISHU_APP_ID` / `FEISHU_APP_SECRET` — 飞书开放平台应用凭证
- 企微文档凭证 — 通过企微文档 MCP / 对应环境变量配置（见 wdp-kb-ops）

## 技能清单

| 技能 | 用途 | 加载方式 |
|------|------|---------|
| `wdp-product-knowledge` | 产品知识索引：编辑器/API/报价/部署/FAQ/版本日志 | `skill_view(name='wdp-product-knowledge')` |
| `wdp-kb-ops` | 知识库运维：在线文档路由、认证授权、同步流程 | `skill_view(name='wdp-kb-ops')` |

## 子任务场景

| 场景 | 说明 |
|------|------|
| 售后技术支持 | 接收客户问题 → 匹配 FAQ 路由 → 拉取在线文档 → 排查回复 |
| API 技术支持 | 接收开发者问题 → 拉取 Skill 库 manifest → 定位 SKILL.md → 输出代码示例 |
| 对外文档生成 | 三路交叉引用（编辑器+API库+版本日志）→ 生成 Word .docx |
| 知识库同步 | 定时拉取在线文档 → 过滤图片 → 对比变化 → 自动更新 skill |

## 自动化

两个 cron 任务每日自动执行：
- **知识库同步**（18:00）：检查在线文档更新 → 自动更新 skill
- **API 文档审查**（17:30）：检查 Skill 库变更 → 验证输出文档准确性

## 参与方式

1. 加载对应 skill 获取产品知识上下文
2. 按子任务场景输入 prompt（见 templates 目录）
3. 所有回答以在线源拉取结果为准，本地快照仅作索引
