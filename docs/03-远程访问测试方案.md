# 远程访问测试方案

> 目的：在纯本机环境下验证 Hermes WebUI 功能可用，作为正式部署前的可行性验证。
> **本方案不涉及远程访问/内网穿透**——你本机测完确认功能 OK 后，再让 IT 部署到服务器给同事用。

## 测试目标

1. Hermes WebUI 服务能正常启动
2. 浏览器能正常打开对话界面、发起对话、收到流式回复
3. agent 能读写共享目录（knowledge/），证明知识资产落盘可行

## 本机功能测试（10分钟）

### 步骤

1. **启动服务**：双击 `scripts/start-test-server.bat`
   - 会弹出一个黑窗口
   - 窗口里显示 `Local LAN IP: 10.66.8.33` / `Listen port: 8799` 即启动成功
   - **关闭窗口即停止服务**

2. **本机浏览器打开**：
   ```
   http://127.0.0.1:8799
   ```

3. **测试对话**：随便发一句，比如 "你好，请回复 OK 并告诉我今天的日期"

4. **测试写文件**：发这句，验证 agent 能写共享知识库：
   ```
   请在 F:\wdp-team-hermes\knowledge\signals\ 目录下创建一个文件 test.md，内容是"# 本机功能测试\n测试时间：<当前时间>"
   ```

5. **验证文件落盘**：到 `F:\wdp-team-hermes\knowledge\signals\` 看 `test.md` 是否生成

### 验证通过标准

- [ ] 浏览器能打开 WebUI 界面
- [ ] 能发起对话并收到流式回复
- [ ] agent 能写文件到 `knowledge/` 目录
- [ ] 关闭窗口后服务停止，端口释放

## 测完之后

功能验证 OK 后：

1. 把 `docs/02-部署checklist-给IT.md` 转给 IT
2. IT 在你们服务器部署完成
3. 同事直接访问服务器 IP 即可使用
